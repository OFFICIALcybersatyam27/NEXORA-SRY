☠️ NEXORA-SRY

NEXORA-SRY is an OSINT (Open-Source Intelligence) and information-gathering tool designed to collect publicly available information through IP addresses, phone numbers, and usernames.

A lightweight information-gathering project built for educational purposes and authorized research.

"Version 1.0"

✨ Features

- 🌐 IP Information — Gather publicly available IP-related information.
- 📱 Phone Information — Retrieve available phone-number details.
- 👤 Username Search — Search for publicly available username information.
- ⚡ Simple Interface — Easy-to-use terminal interface.
- 🐍 Python Powered — Built using Python.

📥 Installation on Linux

sudo apt update
sudo apt install git python3 python3-pip

📥 Installation on Termux

pkg update
pkg install git python

⚙️ Installation & Usage
```
git clone https://github.com/OFFICIALcybersatyam27/NEXORA-SRY.git
cd NEXORA-SRY
pip install -r requirements.txt
python SRY.py
```

"Phone Information"

"Username Search"
